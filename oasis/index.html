Interactive · rare-event detection in a live image stream

Catch the rare event, one image at a time.

A telescope revisits the same patch of sky at irregular times, and each visit returns one image in one of four colour filters. Very rarely the stream contains a gravitationally lensed supernova; far more often, a look-alike. OASIS is a transformer that updates its verdict after every new image, using only the images that have actually arrived: no fixed grid, no zero-padding, no peeking at the future.

Decide after every frame

A fresh probability after each new image, not after the stream ends. For rare, short-lived events, early alerts are what make follow-up possible.

Irregular, multi-sensor input

Frames arrive at uneven times from four different filters. The model takes the stream as it comes, with real timestamps, instead of forcing it onto a schedule.

No imputation

A grid model must invent values for 75% of its inputs. Attention works directly on the observations that exist, so nothing is filled in.

Beyond astronomy

The same shape of problem appears wherever images arrive irregularly from several sensors and a decision cannot wait for the full sequence.

How OASIS works, in five lines

Tokens. Each image is cut into a 9 × 9 grid of patches; every patch becomes a token tagged with its filter and its exact arrival time.

Space, then time. Attention first mixes the 81 patches within an image, then lets each patch position look at the same position in earlier images. A causal mask forbids looking ahead.

Readout. In the best design (A2), one learned query per time step reads the tokens visible so far and outputs the probability of a lensed SN.

Training. The loss is applied after every image, so every partial stream is a valid prediction point. All seven designs share one recipe; only the architecture changes.

Evaluation. All numbers on this page are held-out test-set statistics from the paper; the streams shown are real simulated test examples, but no per-stream score is shown.
